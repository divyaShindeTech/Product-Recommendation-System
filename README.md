# Product Recommendation System

## Project Objective

Build a Product Recommendation System using Product-Product Collaborative Filtering on product ratings data.

## Techniques Used

* Data Cleaning
* Exploratory Data Analysis (EDA)
* K-Means Clustering
* Product-Product Collaborative Filtering
* Cosine Similarity

## Deployment

Built using Streamlit and deployed on Streamlit Community Cloud.

## Files

* app.py
* product_similarity.pkl
* product_ids.pkl
* requirements.txt

## Recommendation Method

Products are recommended based on similarity scores computed using cosine similarity between products.
